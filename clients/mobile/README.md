# DirLocker Mobile Client (Flutter)

A secure, cross-platform mobile file vault built with **Flutter** (UI) and **Rust** (Core Logic).

## 📱 Features

*   **🔒 Secure Vaults**: Creates and opens encrypted vaults using XChaCha20-Poly1305.
*   **📂 File Management**: Import, Delete, and List files securely.
*   **👀 Secure Viewing**: Decrypt and view text files on the fly without writing to disk.
*   **⚡ Native Performance**: Powered by a shared Rust core library via FFI.
*   **👆 Modern UI**: Navigation, Material 3 design, and intuitive controls.

## 🛠️ Prerequisites

To build and run this project, you need:

1.  **Flutter SDK**: [Install Flutter](https://docs.flutter.dev/get-started/install). verify with `flutter doctor`.
2.  **Rust Toolchain**: [Install Rust](https://rustup.rs/). Verify with `cargo --version`.
3.  **Android Studio / Xcode**: For emulators and native build tools.
4.  **Codegen Tool**:
    ```bash
    cargo install flutter_rust_bridge_codegen@^2.0.0
    ```

## 🚀 Setup & Build

### 1. Initialize Bindings
The communication between Dart and Rust is handled by `flutter_rust_bridge`. You must generate the bindings before running the app.

Run the following command from this directory (`clients/mobile`):

```bash
flutter_rust_bridge_codegen generate \
    --rust-input ../../vault-core/src/mobile_api.rs \
    --dart-output ./lib/bridge_generated.dart \
    --c-output ./ios/Runner/bridge_generated.h \
    --rust-root ../../vault-core
```

### 2. Run the App
Launch the app on a connected device or emulator:

```bash
flutter run
```

### 3. Build for Production

#### Android APK
```bash
flutter build apk --release
```
The output will be in `build/app/outputs/flutter-apk/app-release.apk`.

#### iOS (macOS only)
```bash
flutter build ios --release
```

## 🧪 Architecture

*   **UI Layer (Dart/Flutter)**: Handles user interaction, state management, and screens (`VaultAccessScreen`, `VaultDashboardScreen`).
*   **Bridge Layer (FFI)**: Generated by `flutter_rust_bridge`, marshals data between Dart and Rust.
*   **Core Layer (Rust)**: The `vault-core` crate (shared with Desktop/CLI). Handles encryption, disk I/O, and key management.

## ⚠️ Limitations

*   **Directory Upload**: Currently, only individual file selection is supported via the system picker.
*   **Binary View**: Binary files are detected but currently only display metadata (size) rather than rendering (e.g., images/videos).
*   **Background Sync**: Vault operations are synchronous to the UI interactions in this version.
